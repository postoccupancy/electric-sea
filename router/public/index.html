SETUP HELP
ALL PLATFORMS
Use Chrome — Firefox and Safari do not support WebMIDI
Accept the certificate warning on first visit
Allow MIDI access when Chrome asks
MAC
1. Open Audio MIDI Setup (Spotlight)
2. Window → Show MIDI Studio
3. Double-click IAC Driver → Device is online → add Bus
4. Refresh page — IAC Driver appears in ports table
5. In Live: Preferences → MIDI → IAC → Track ON, Remote ON
WINDOWS
1. Download loopMIDI from tobias-erichsen.de
2. Install, open, click + to create a port
3. Refresh page — loopMIDI port appears
SIGNAL FORMAT — WebSocket JSON
Connect to wss://rf.postoccupancy.com or wss://10.0.0.1:3000

osc — physical sensor:
{
  "type": "osc",
  "device": "osc/indoor-sky/temperature",
  "value": 22.3,
  "source": "adrian-pi"
}
json — browser or HTTP origin, float 0–1:
{
  "type": "json",
  "device": "json/moire/interference",
  "value": 0.847,
  "source": "192.168.0.5"
}
midi — MIDI controller via WebMIDI API or Pi USB:
{
  "type": "midi",
  "device": "IAC Driver Bus 1",
  "msgType": "cc",
  "channel": 1,
  "cc": 1,
  "value": 64
}
OSC — automatic on port 9000
Every directly connected client gets all signals as OSC UDP on port 9000. UDP output is disabled when the page is reached through a web tunnel such as Cloudflare.

TouchDesigner: OSC In CHOP → port 9000
VCV Rack: VCV OSC module → port 9000
Max for Live: udpreceive 9000
CHANNEL ASSIGNMENTS
Ch/CC assignments are saved in your browser's localStorage by device name.
They persist across page refreshes and Pi reboots.
To clear all assignments: open browser console and run localStorage.clear() then refresh.
